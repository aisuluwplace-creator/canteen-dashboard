# Опросы удовлетворённости — дашборд

Streamlit-дашборд по трём опросам сотрудников: столовая, транспорт (развозка), медстраховка (ДМС).
Сравнивает последнюю волну опроса с периодом сравнения, показывает KPI с проверкой статистической
значимости, автоматические выводы, распределения ответов и комментарии с тональностью и темами.

## Запуск

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Файлы данных (выгрузки MS Forms `*.xlsx`) лежат рядом с `streamlit_app.py`; какой файл к какому разделу
относится — задано в `config.py` (`file_glob`). Приложение разворачивается на Streamlit Community Cloud
без дополнительных настроек: тяжёлые ML-зависимости в `requirements.txt` не входят.

## Структура

| Файл | Назначение |
|---|---|
| `streamlit_app.py` | сборка страницы: вкладка «Обзор» + вкладка на каждый раздел |
| `config.py` | **вся конфигурация**: палитра, описание опросов (колонки, вопросы, шкалы), пороги, подписи шкал, темы комментариев |
| `i18n.py` | тексты интерфейса на RU / KZ / EN |
| `data.py` | загрузка файлов, периоды, волны, дата обновления, текст вопроса из заголовка колонки |
| `metrics.py` | средний балл, доли довольных/недовольных, проблемная метрика, сводка по вопросам |
| `stats.py` | значимость: Манн–Уитни для шкал 1–5, z-тест для долей |
| `insights.py` | правила блока «Ключевые выводы» |
| `formatting.py` | форматирование чисел и дат (1 422 · 3,6 · −4,0% · +5 п.п.) |
| `charts.py` | графики Plotly |
| `components.py` | стили, шапка, KPI-карточки, карточки «Да/Нет», выводы, обзор |
| `comments.py` | очистка комментариев, эвристика тональности, дубли, загрузка результатов модели |
| `scripts/` | офлайн-скрипты (см. ниже) |
| `data/` | результаты офлайн-скриптов |

## Пороги и настройки (`config.py`)

- `MIN_WAVE_SIZE` — минимум анкет в месяце, чтобы месяц считался волной опроса;
- `SIGNIFICANCE_ALPHA`, `MIN_N_FOR_TEST` — порог p и минимальный размер выборки для теста
  (меньше — «мало данных для сравнения»);
- `NEGATIVE_SHARE_ALERT`, `POLARIZATION_PP`, `INSIGHTS_MAX` — правила выводов;
- `SCALE_LABELS` — расшифровка концов шкал 1–5 (значения `None` — **TODO**, требуют уточнения формулировок анкеты);
- `satisfaction_col` / `problem_col` в `SurveyConfig` — главный вопрос удовлетворённости и главная проблемная метрика
  (`None` — сводный балл по всем шкалам / авто-выбор по доле негативных ответов);
- `TOPICS`, `TOPIC_SIM_THRESHOLD` — темы комментариев и порог отнесения к «Прочее»;
- `MIN_COMMENT_LEN`, `MAX_FEED_COMMENTS`, `ANONYMITY_MIN_GROUP` — лента комментариев и анонимность сегментов.

## Тональность и темы комментариев (офлайн)

Дашборд работает и без моделей — на эвристике по ключевым словам. Чтобы включить модельную
тональность и темы, один раз локально:

```bash
pip install -r requirements-dev.txt          # torch, transformers, sentence-transformers …
python scripts/score_comments.py             # → data/comments_scored.csv (несколько минут, модели скачиваются при первом запуске)
```

Русский текст — `blanchefort/rubert-base-cased-sentiment`, казахский (по буквам ә ғ қ ң ө ұ ү һ і) —
`cardiffnlp/twitter-xlm-roberta-base-sentiment`; темы — косинусная близость эмбеддингов
`paraphrase-multilingual-MiniLM-L12-v2` к описаниям тем из `config.TOPICS`. Файл `data/comments_scored.csv`
коммитится в репозиторий — на Streamlit Cloud модели не нужны. После обновления файлов опроса скрипт
нужно перезапустить.

## Ручная разметка и оценка качества

```bash
python scripts/make_labeling_template.py     # → data/manual_labels.csv: 50 случайных комментариев
# заполнить колонки true_sentiment (pos / neu / neg) и true_topic (ключ темы или other)
python scripts/evaluate.py                   # → data/model_metrics.json: accuracy и macro-F1
```

Если `data/model_metrics.json` есть, дашборд показывает строку «Точность определения тональности: N%…»
и убирает оговорку про сарказм из подвала.

## Проверки

```bash
python scripts/check_names.py     # комментарии, где могут быть имена — для ручной проверки, ничего не удаляет
python scripts/smoke_test.py      # приложение стартует без ошибок на трёх языках
python scripts/check_ui.py        # аудит текстов (латиница, форматирование чисел) и граничных случаев фильтров
python scripts/screenshot.py out/ # скриншоты вкладок (нужен playwright)
```
